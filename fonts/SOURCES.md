# Bundled fonts

All fonts are served locally by `next/font/local`; builds do not call Google Fonts.

- `PlusJakartaSans-Variable.ttf`: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/plusjakartasans). License: `PlusJakartaSans-OFL.txt`.
- `NotoSansDevanagari-Variable.ttf`: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notosansdevanagari). License: `NotoSansDevanagari-OFL.txt`.
- Existing Quicksand files: see `OFL.txt` and `README.txt`.
